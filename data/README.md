# Project Data

The repository contains a **fully synthetic teaching dataset** under `data/synthetic/`, generated by `src/generate_synthetic_dataset.py`. It contains fictional records created for demonstrating data ingestion, validation, SQL, and dashboards. It is not evidence about a real company or market.


Run the generator from the repository root:

```bash
python3 src/generate_synthetic_dataset.py
```

See `data/synthetic/README.md` and `docs/synthetic-data-card.md` for contents and limitations. Raw third-party files under `data/raw/` remain excluded by `.gitignore`.
