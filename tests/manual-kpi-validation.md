This note records two order-level spot checks against the deterministic CSVs generated by `src/generate_synthetic_dataset.py`. It supplements—not replaces—the automated structural validator and SQL/dashboard reconciliation.

## Cancelled order: ORD-000036

**Source:** `data/synthetic/orders.csv` and `data/synthetic/order_lines.csv`.

| Check | Source values | Expected treatment |
|---|---|---|
| Status | `cancelled` | Count in submitted orders and cancellation metrics |
| Promised date | 2025-01-13 | Not used to assess delivery service for a cancelled order |
| Actual date | blank / SQL `NULL` | No delivery occurred |
| Line quantities | Four lines; 19 units ordered and 0 delivered | Do not assess as an in-full service order |

**Metric treatment:** include this order in the cancellation numerator and submitted-order denominator. Exclude it from the on-time, in-full, and OTIF delivery-service denominators, consistent with [`docs/metric-definitions.md`](../docs/metric-definitions.md).

## Reproduce the source checks in PostgreSQL

After loading the synthetic data using the project database setup instructions, run:

```sql
SELECT order_id, order_status, promised_delivery_date, actual_delivery_date
FROM supply_chain.orders
WHERE order_id IN ('ORD-000001', 'ORD-000036')
ORDER BY order_id;

SELECT order_id, line_id, ordered_qty, delivered_qty
FROM supply_chain.order_lines
WHERE order_id IN ('ORD-000001', 'ORD-000036')
ORDER BY order_id, line_number;
```

Compare the returned rows with the expected classifications above and with the KPI rules in `docs/metric-definitions.md`. The files are deterministic, so regeneration with the documented generator should reproduce these examples.

## Limitations

These are two selected example records, not a statistically representative sample or a complete test suite. They confirm the visible date, quantity, status, and denominator rules for these cases only. Also verify edge cases (late delivery, a short line, and a multi-line order with one short line) before claiming comprehensive KPI validation.
